# Scrapbook working records

This directory holds cross-project material prepared in Stensibly for possible
use by Scrapbook. It is not a second copy of the Scrapbook repository and it is
not automatically published.

Each record must state its own status. Exploratory records preserve a product
model or useful line of inquiry. Ready-to-publish records are edited artifacts
that can be sent to Scrapbook with their source evidence attached.
